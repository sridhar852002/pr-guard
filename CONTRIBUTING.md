# Contributing — Qodo PR workflow

Required for the [Agent Harness Hackathon](https://www.wemakedevs.org/hackathons/trueforge).

## Workflow

1. Branch from `main`
2. Open a pull request with a clear title and description
3. Qodo reviews automatically, or comment `/agentic_review` on the PR
4. Fix every valid **High** finding (or dismiss with reason in the Qodo thread)
5. Push fixes → comment `/agentic_review` again
6. Merge when Highs are cleared — never push substantive work directly to `main`
