# Contributing

Hackathon workflow — required by WeMakeDevs rules:

1. Branch from `main`
2. Open a pull request
3. Comment `/agentic_review` on the PR
4. Fix High-severity Qodo findings (dismiss others with reason in thread)
5. Push fixes, run `/agentic_review` again
6. Merge via PR — never push substantive work directly to `main`

See [`WIN.md`](WIN.md) for the full submission playbook.
